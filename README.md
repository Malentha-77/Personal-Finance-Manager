# Personal Finance Manager

A beginner Python project for managing personal income and expenses.

## Features

* View all financial records
* Add income and expense records
* Remove financial records
* Find records by name
* Calculate total income
* Calculate total expenses
* Calculate the current balance
* Validate user input
* Save records to a JSON file
* Interactive menu

## Technologies

* Python
* JSON

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python main.py
   ```

## Data Storage

Financial records are stored in `finances.json`. Changes are saved automatically when records are added or removed.
